# 📹 Video 3: Git and GitHub for Beginners - Crash Course
Este taller rápido me ofreció una introducción general a Git y GitHub, especialmente dirigida a quienes comienzan. Inició con una explicación sobre el control de versiones y su relevancia en el desarrollo de software, sobre todo en trabajos colaborativos.

Aprendí a instalar Git, configurar mi usuario y crear un repositorio local. Se enseñaron comandos básicos como git status, git diff, git log y git reset que permiten supervisar y manejar los cambios realizados en el código.

El video también cubrió la relación entre Git y GitHub, ilustrando cómo generar un repositorio remoto, enlazarlo con el local y sincronizar los cambios con git push y git pull. Además, se explicó cómo identificar y resolver conflictos de fusión (merge conflicts) de manera efectiva.

Este curso me proporcionó un conocimiento práctico para emplear Git y GitHub en proyectos reales, fortaleciendo mi capacidad de trabajo en equipo y de mantener un registro claro de las modificaciones en el código.
