# 📹 Video 1: Git Tutorial For Beginners 2022 | Git & GitHub Complete Tutorial | Learn Git in 2 hrs | Simplilearn
En este video, adquirí conocimientos básicos sobre Git y GitHub, herramientas clave para el manejo de versiones en el desarrollo de software. Entendí cómo Git facilita el seguimiento de modificaciones en el código, lo que mejora la colaboración entre programadores y la organización de proyectos.

El tutorial incluyó comandos esenciales como git init, git add, git commit, git push y git pull, necesarios para gestionar repositorios tanto locales como remotos. También se explicó el uso de las ramas (branches), que permiten crear nuevas funcionalidades sin alterar la versión principal del proyecto.

Adicionalmente, se mostró cómo utilizar GitHub como una plataforma en la nube para hospedar repositorios, compartir proyectos y trabajar conjuntamente con otros desarrolladores. Aprendí a crear un repositorio en GitHub, clonarlo en mi computador y mantener sincronizados los cambios entre ambos.
