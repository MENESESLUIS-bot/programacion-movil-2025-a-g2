#  Video 2: GitHub Tutorial - Beginner's Training Guide
Este video me brindó una introducción al uso de GitHub, centrándose en la gestión de proyectos y la colaboración con otros desarrolladores. Aprendí a manejar la interfaz de GitHub, entendiendo las partes principales como repositorios, issues, pull requests y el archivo README.

Se explicó el proceso para crear un repositorio nuevo, añadir archivos, hacer commits y utilizar ramas para trabajar en distintas versiones del proyecto. También se mostró cómo colaborar mediante forks y pull requests, lo que permite sugerir cambios y revisarlos antes de integrarlos al proyecto principal.

El tutorial resaltó la relevancia de los issues para hacer seguimiento de tareas y errores, ayudando así en la organización del proyecto. Aprendí a usar etiquetas, asignar responsables y cerrar issues cuando se resuelven.

En resumen, este video fortaleció mi entendimiento de GitHub como una herramienta colaborativa fundamental en el desarrollo de software, facilitándome la gestión más eficiente y ordenada de los proyectos.
